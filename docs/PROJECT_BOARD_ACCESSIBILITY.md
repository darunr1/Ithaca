# Accessible project board

Use Tab/Shift+Tab to reach native details, forms, status controls and page controls. Task and milestone status selects have specific accessible names. Saves temporarily disable editable controls to prevent double submissions. Success refreshes and focuses the status announcement; failures preserve input and announce the error, with failed status changes restored. Task version conflicts reload current data. Narrow screens stack lanes and controls. Automated tests cover rendering and save lifecycle; manual keyboard and mobile browser checks are still recommended.
